QUICK GUIDE

从这里开始

  1. 选择服务器

    左侧自动读取 ~/.ssh/config 的 Host 别名。点 ↻ 刷新；切换服务器会切换整套工作区，并保留其他连接。

  2. 给窗口命名

    点“新建窗口”。名称支持中文。服务器上的会话使用带唯一后缀的标识，避免重名。

  3. 布置你的空间

    拖动标题栏移动、拖动边缘缩放，双击标题栏最大化。A− / A＋ 调整终端字号；布局自动保存。

  4. 决定任务的去留

    窗口 × 可选择分离或结束。“关闭服务器”可逐个选择 Detach / Close；Detached 窗口恢复布局但不自动连接，已 Close 的会话不再显示。

服务器需要安装 GNU screen，适用于终端程序，例如 bash、Python、htop、vim。图形桌面应用不在本版本范围内。
复制：选中文字后 ⌘C / Ctrl+Shift+C。粘贴：⌘V / Ctrl+Shift+V。screen 原有快捷键仍可使用。
